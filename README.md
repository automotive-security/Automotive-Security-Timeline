# Automotive Security Timeline

**Automotive Security Timeline** is an open-source knowledge base dedicated to automotive cybersecurity. It continuously documents significant cybersecurity events across the global automotive ecosystem, including vulnerability disclosures, security research, attack demonstrations, data breaches, and other major security incidents.

As Connected Vehicles and Software-Defined Vehicles (SDVs) continue to evolve, automotive security incidents have become increasingly frequent. However, relevant information is often scattered across conference presentations, vendor advisories, media reports, vulnerability databases, and research blogs, making it difficult to search, correlate, and understand from a historical perspective. This project aims to organize these fragmented resources into a chronological timeline, providing researchers and practitioners with a comprehensive view of the evolution of automotive cybersecurity and emerging security trends.

## Scope

The timeline continuously collects and maintains, but is not limited to, the following categories:

- Automotive cybersecurity vulnerabilities (IVI, T-Box, ECU, ADAS, EV charging infrastructure, etc.)
- Security research and vulnerability disclosures
- Research presented at conferences such as Black Hat, DEF CON, and Pwn2Own Automotive
- Security incidents involving OEMs, Tier 1 suppliers, and the automotive supply chain
- Data breaches, ransomware incidents, and other cybersecurity events

Whenever possible, each entry includes a brief description, publication date, references, and related images or videos to facilitate further research and citation.

## Project Goals

- Build a comprehensive historical archive of automotive cybersecurity events.
- Help researchers quickly locate and review historical security incidents.
- Support vulnerability research, threat intelligence, and security analysis.
- Provide reliable reference material for technical presentations, academic publications, and cybersecurity training.
- Foster an open and continuously evolving knowledge base for the automotive cybersecurity community.

## Contributing

Automotive Security Timeline is a long-term open-source project. Contributions from the global automotive cybersecurity community—including OEMs, Tier 1 suppliers, research institutions, and independent security researchers—are highly encouraged.

If you discover new security incidents, research findings, or historical information that should be included, please feel free to submit an Issue or Pull Request to help improve this growing timeline.
