## 汽车安全事件时间轴

汽车安全事件时间轴 是一个专注于车联网领域的开源安全事件知识库，致力于持续记录全球汽车网络安全的重要事件、漏洞披露、安全研究、攻防演示、数据泄露等。

随着智能网联汽车和软件定义汽车的快速发展，汽车安全事件数量不断增加，但相关信息长期分散于会议论文、厂商公告、媒体报道、漏洞平台和研究博客中，检索成本高、时间跨度长、缺乏统一的时间视角。本项目希望通过时间轴的方式，将这些碎片化信息进行整理、关联和持续更新，帮助研究人员快速了解行业发展脉络与安全趋势。汽车网络安全的重要性也随着车辆联网程度和软件复杂度提升而持续增长。

## 收录范围

目前时间轴持续收录包括但不限于：

- 车联网安全漏洞（IVI、T-Box、ECU、ADAS、充电设施等）
- 安全研究成果与漏洞披露
- Black Hat、DEF CON、Pwn2Own Automotive 等安全会议研究
- OEM、Tier1、供应链安全事件
- 数据泄露与勒索软件事件等

每个事件均尽可能提供事件简介、发布时间、参考来源及相关图片或视频，方便进一步查阅和引用。

## 项目目标

- 建立完整的车联网安全历史档案，记录行业发展历程。
- 帮助研究人员快速查找历史事件，减少资料收集成本。
- 辅助安全研究、漏洞分析和威胁情报工作。
- 为技术分享、论文、培训及演讲提供可靠参考素材。
- 构建开放共享的汽车网络安全知识库。

## 开源共建

汽车安全事件时间轴 是一个长期维护的开源项目，我们欢迎来自全球汽车安全社区、OEM、Tier1、研究机构以及独立安全研究人员共同参与维护。

如果您发现新的汽车安全事件、漏洞研究或历史资料遗漏，欢迎提交 Issue 或 Pull Request，一起完善这份持续增长的汽车网络安全历史记录。
